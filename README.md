# Furnace + Cougar: static advertising page (React + Vite)

No backend. `npm run build` produces plain HTML, CSS and JS in `dist/`.

```
npm install
npm run dev      # local preview
npm run build    # static site in dist/
```

## Edit
- `src/data/products.js`: the pictures in the gallery (names, colours, order).
- `public/images/`: your photos.

## Host it
Upload `dist/` to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages).
